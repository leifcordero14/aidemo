# 🤖 Demostración de IA

Un proyecto en Go que compara la inteligencia artificial clásica y la moderna mediante dos implementaciones: la toma de decisiones basada en reglas y el aprendizaje basado en datos. La IA clásica utiliza condiciones predefinidas para recomendar actividades según el clima, la temperatura y si es fin de semana, mientras que la IA moderna aprende un umbral de temperatura promedio a partir de datos de entrenamiento para clasificar las temperaturas como altas o bajas.

## </> Tecnologías

- `Go`

## ✨ Características

Esto es lo que puedes explorar en este proyecto:

- **IA clásica**: Utiliza reglas predefinidas y estructuras condicionales para recomendar actividades según el clima, la temperatura y si es fin de semana.

- **IA moderna**: Utiliza datos de entrenamiento para calcular un umbral de temperatura promedio y clasificar nuevas temperaturas como "Altas" o "Bajas".

- **Toma de decisiones basada en reglas**: Demuestra cómo la IA clásica sigue condiciones programadas explícitamente para tomar decisiones.

- **Clasificación basada en datos**: Muestra cómo un modelo de IA moderno utiliza datos numéricos para realizar predicciones basadas en un umbral aprendido durante el entrenamiento.

- **Comparación de IA**: Destaca las diferencias entre los sistemas basados en reglas y los modelos basados en datos mediante ejemplos sencillos y prácticos.

## 🚦 Cómo ejecutar el proyecto

Para ejecutar el proyecto en tu entorno local, sigue estos pasos:

1. Clona el repositorio en tu equipo.
2. Accede al directorio del proyecto.
3. Ejecuta `go run .` para compilar y ejecutar el programa.
