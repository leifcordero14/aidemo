# 🤖 AI Demo

A Go project that compares classical AI and modern AI through two implementations: rule-based decision-making and data-driven learning. The classical AI uses predefined conditions to recommend activities based on weather, temperature, and weekends, while the modern AI learns an average temperature threshold from training data to classify temperatures as high or low.

## </> Technologies

- `Go`

## ✨ Features

Here's what you can explore in this project:

- **Classical AI**: Uses predefined rules and conditional statements to recommend activities based on weather, temperature, and whether it's a weekend.

- **Modern AI**: Uses training data to calculate an average temperature threshold and classify new temperatures as "High" or "Low."

- **Rule-Based Decision Making**: Demonstrates how classical AI follows explicitly programmed conditions to make decisions.

- **Data-Driven Classification**: Shows how a modern AI model uses numerical data to make predictions based on a threshold learned during training.

- **AI Comparison**: Highlights the differences between rule-based systems and data-driven models through simple, practical examples.

## 🚦 How to Run

To run the project in your local environment, follow these steps:

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Run `go run .` to compile and execute the program.

<br />

> [!IMPORTANT]
> Go must be installed on your machine before running the program. You can verify your installation by running `go version` in your terminal.
